Open source

Anything that isn't yours, we publish.

Conservation groups keep paying separately for the same models. Where work is general rather than tied to one site or one dataset, it should be published so the next group doesn't start from zero.

How we'll publish

  • Permissive licence — use it commercially, fork it, no permission needed
  • Weights and code together, with the data sources named
  • Written down: what it was trained on, where it fails, what it should not be used for
  • Sized to run on a laptop or a field machine, not only on a cluster
  • Sensitive locations stripped before anything goes public
  • Issues answered — a repository nobody maintains isn't a contribution
